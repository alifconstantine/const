# Const Learn Release Downloads Folder

This folder serves static download files directly via Next.js at `/downloads/<filename>`.

To serve direct installer files from this web server:
1. Place your Windows installer here: `Const-Learn-Setup-x64.exe`
2. Place your Windows ARM64 installer here: `Const-Learn-Setup-arm64.exe`
3. Place your macOS DMG here: `Const-Learn-arm64.dmg` / `Const-Learn-x64.dmg`
4. Place your Linux package here: `Const-Learn-x86_64.AppImage` / `const-learn_amd64.deb`
5. Place your Android APK here: `Const-Learn.apk`

Alternatively, the download page links can point to GitHub Releases:
https://github.com/alifconstantine/const/releases/latest
