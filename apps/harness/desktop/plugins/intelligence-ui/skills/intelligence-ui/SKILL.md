# Interactive chat responses

Read [the OpenUI language and component reference](references/openui.md) before writing an interactive response. It specifies the exact syntax and registered components supported by this desktop app.

Wrap each complete program in an unindented `openui-lang` fenced code block. Keep ordinary explanations in Markdown around the blocks. Use verified or user-supplied data and label sample data only when requested.

The reference describes chat output, not permission to modify files or perform external actions. Follow the current task and normal tool permissions.
