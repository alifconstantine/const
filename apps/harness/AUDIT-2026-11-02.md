## Computer Use dan lifecycle

- Desktop fisik merupakan satu resource bersama. Controller memiliki antrean operasi dan pemilik session; chat kedua memperoleh `desktop_busy` selama pemilik pertama belum selesai atau lease belum kedaluwarsa.
- Snapshot dan indeks elemen dipisahkan per session, serta tindakan dipasangkan ke PID/window yang diamati. Indeks lama tidak boleh digunakan setelah cache dibersihkan.
- Runtime native memiliki deadline request 30 detik dan startup 15 detik. Pembatalan menghentikan worker; finalisasi run melepas kepemilikan desktop dan pertanyaan yang tertunda.
- Agent session registry menggunakan `runId`, sehingga run lama tidak dapat menghapus penggantinya. Finalisasi tetap dilakukan setelah run unwind; jalur abort tidak melepaskan pemilik sebelum trailing result diterima.
- Background jobs dibatasi berdasarkan conversation ID pada operasi agent. Selesai/error/stop memperbarui status; server sengaja dapat bertahan setelah jawaban agent selesai agar preview tetap dapat dibuka.

## Batasan yang masih perlu diketahui

- Isolasi browser di sini adalah isolasi tab, routing, kontrol, dan operasi task. Cookie/login masih memakai profil browser aplikasi yang sama (`persist:const_browser`). Ini bukan browser profile atau OS desktop terpisah untuk setiap workspace.
- Membuka halaman Skills atau Scheduled Tasks masih melepas subtree workspace, termasuk guest browser. Persistensi guest yang ditambahkan mencakup perpindahan chat/workspace dan penutupan SidePanel. Kegagalan JavaScript akibat guest ditutup sekarang dibatasi dan dilaporkan; mempertahankan guest melewati pergantian halaman tersebut membutuhkan pemindahan host browser ke luar subtree workspace.
- Deadline 30 detik diterapkan pada Promise halaman JavaScript; ini bukan jaminan bahwa setiap operasi CDP memiliki deadline universal. Pembatalan menghentikan penantian host dan mencegah tool berikutnya; efek halaman yang sudah dikirim tidak di-rollback otomatis.
- Kontrol Computer Use diuji dengan bridge fixture, tanpa mengirim input ke aplikasi pengguna. Pengujian native macOS/Linux tidak dijalankan dari mesin Windows ini.
- Detector UI menemukan sembilan advisory desain lama di bagian yang tidak diubah (ukuran font, radius, dan warna element picker). Tidak ada temuan blocking dari detector.
- Perubahan Electron/agent memerlukan restart atau rebuild aplikasi. Perubahan ini tidak memulihkan run lama yang sudah tersangkut secara retroaktif.
