# Router redesign

Landing: Persuade. Console: Operate. Documentation: Read.

## Direction contract

THESIS: Make the route from model comparison to first request obvious, and costs and execution state inspectable. Replace the promotional card wall with product-led composition and precise working screens.

OWN-WORLD: Black and graphite, warm white ink, restrained champagne selection and usage series, Manrope typography, conventional controls, open grouped sections, and deliberate whitespace. Keep the Const mark and desktop particle backdrop.

STORY: Explain the shared API, show an executable integration, compare canonical rates, then enter the console. Real usage and account controls lead inside; documentation answers integration questions without unsupported guarantees.

FIRST VIEWPORT: Desktop landing pairs a large left-aligned headline with an actual integration panel over the existing backdrop. Mobile removes the backdrop and stacks the headline, action, and connection details. Console uses a compact navigation rail, quiet toolbar, period-filtered analytics and distinct task areas. Docs have topic navigation and a calm reading measure.

FORM: Code-led redesign; style and layout delegated by the user's request. No raster comp or randomized concept selection. Existing behavior and explicit black/hero constraints are binding.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
