# Router design and content audit

Completed 1 November 2026. Scope: the landing page, Overview, Playground, Models & pricing, Endpoints, Credits, Settings, Docs, and their shared navigation.

The new system keeps the black foundation and existing desktop particle artwork, with graphite surfaces, warm white text, Manrope typography, and restrained champagne accents. Mobile has a distinct hero without the particle scene. Light appearance remains available in the console.

| Surface | Findings and changes |
| --- | --- |
| Landing | Replaced repeated promotional cards with a product introduction, executable integration, routing explanation, canonical model rates, and a clear starting action. Desktop pairs headline and request code. Mobile shows labeled input/cache/output rates directly. |
| Overview | Replaced the limited activity display with period and metric controls, full-period aggregation, accessible chart data, explicit billing units, allowance context, and readable model/request tables. Loading, empty, and error states remain distinct. |
| Playground | Removed saved conversation queries, persistence, titles, and history UI. Retained current-session prompts, attachments, streaming, cancellation, model/system controls, and request code. |
| Models & pricing | Removed duplicated competitor comparisons and unsupported savings claims. Search, category, and tier filters use the actual catalog; pricing identifies token, minute, and search units. |
| Endpoints | Replaced generic tiles with searchable method/path/reference rows and working copies. Authentication and responses match implemented routes. |
| Credits | Distinguished available credit, reservations, and spend. Added readable transaction filtering and mobile rows. Funding availability follows the backend rather than promising an unimplemented payment flow. |
| Settings | Grouped actual gateway defaults, privacy, notifications, appearance, and account actions. Preserved save/reset behavior and corrected descriptions of logging and local Playground sessions. |
| Docs | Rebuilt reading layout and topic navigation, executable examples, copy feedback, mobile topic selection, and keyboard-accessible overflow tables. Removed claims unsupported by routes or metering behavior. |
| Shared shell | Unified sidebar, page toolbar, mobile drawer, account menu, focus and loading states. Removed the account menu's language choice that did not translate the interface. Fixed nested interactive credit controls and the notification dismiss button's accessible name. |

## Content corrections

The implementation does not expose a native Anthropic Messages route. Claims of verified uptime, fixed first-token latency, universally exact usage, unbilled interrupted streams, supported payment methods, USD key spending caps, or model allowlists were removed where the implementation did not support them. Pricing now comes from the same catalog as the gateway. Existing credentials, account authentication, and billing contracts were preserved.

## Verification

- All 32 Router regression tests passed, including real Convex subscription stability, authorization, reservations, billing, streaming, Playground history removal, chart aggregation, and sub-microdollar formatting.
- Router TypeScript and the optimized Next.js production build passed.
- Real-browser checks covered every requested page at 1440px desktop and 390px mobile, plus light appearance, filters, copies, settings saves, chart controls, empty/loading/error states, and a synthetic Playground request.
- Console previews use the real components with isolated test-only account/data fixtures. The synthetic request cannot spend model credits and created no saved-history mutations.
- Accessibility checks found and fixed input names, keyboard access, definition-list structure, notification dismissal, and overflow navigation. Mobile tables retain horizontal keyboard access where reference content needs it.
- Desktop particle rendering was verified after reload, navigation, and resizing. A fresh mobile page loads neither its host nor script. Reduced motion suppresses animation.
- The Impeccable detector reported no findings on changed sources. A fresh reviewer inspected all eight surfaces and 20 valid captures. Its sole material finding—offscreen mobile landing prices—was corrected and scored resolved in the follow-up verdict (`ship`). See `.impeccable/review.md` for the scope of that verdict.

Run `node apps/router/tests/serve-ui-preview.cjs` from the repository to reproduce console previews at `http://127.0.0.1:5192`. Production authentication has no fixture or preview bypass.

The design system is documented in `DESIGN.md` and `.impeccable/design.json`. Deployment is separate from this source change.
